# mutlab — мутационное тестирование с mutmut

Учебный проект к практической работе «Мутационное тестирование с mutmut»
(дисциплина «Поддержка и тестирование программных модулей», Лисевич Арсений, Исп/п23-09.2).

Модуль `grading.py` переводит баллы по 100-балльной шкале в оценку, проверяет сдачу
предмета и считает средний балл. Задача — не просто покрыть код тестами, а сделать их
чувствительными к изменению поведения: цель — ни одного выжившего мутанта.

## Структура

| Файл | Назначение |
| --- | --- |
| `grading.py` | оценки, сдача, средний балл, `is_honors` (доп. задание) |
| `setup.cfg` | настройка mutmut: `paths_to_mutate`, `tests_dir`, `runner` |
| `tests/test_grading.py` | итоговый набор тестов (38 проверок) |
| `start_tests.py` | стартовый набор из 8 тестов до усиления |
| `logs/` | вывод всех прогонов pytest и mutmut (основа отчёта) |
| `screenshots/` | 14 скриншотов для отчёта |

## Запуск

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install pytest "mutmut<3"

python -m pytest -q .
python -m mutmut run
python -m mutmut results
python -m mutmut show all
```

`mutmut` нужен версии 2.x: у 3.x другие команды и настройка. Окружение обязательно
активируется: на этой машине `python` без активации попадает в заглушку Microsoft Store,
и mutmut не может запустить тесты (`Tests don't run cleanly without mutations`).

## Результаты

| Этап | Мутантов | Убито | Выжило | MSI |
| --- | --- | --- | --- | --- |
| Стартовые тесты | 21 | 7 | 14 | 33,3 % |
| После усиления тестов | 21 | 21 | 0 | 100 % |
| Доп. задание (`is_honors`) | 23 | 23 | 0 | 100 % |

Покрытие кода стартовым набором — 100 %, но MSI всего 33,3 %: тесты выполняли весь код,
но не проверяли ни одной границы. Выжили мутанты, сдвигающие пороги 60/75/90, меняющие
крайние значения 0 и 100, подменяющие текст ошибки и порог `is_passed`.

## Что исправлено в тестах

- границы по обе стороны каждого порога: 59/60, 74/75, 89/90, а также 0 и 100;
- баллы вне шкалы (−1, 101, −100, 1000) с якорным `match=r"^…$"`, иначе мутант «XX…XX»
  переживает проверку;
- `is_passed` в точке «балл = порог» и с явно переданным порогом, а не только с 80;
- текст ошибки пустого списка с якорями `^…$`.

## Проверка

```powershell
python -m pytest -q          # 38 passed
python -m mutmut run         # 23/23 убито
python -m mutmut results     # выживших нет
```
